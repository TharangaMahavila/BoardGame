# BoardGame – Console Program

A simple and interactive **Python console application** that users can use it for boardgame shop. it connects with the mysql server database and continue as a sample ordering system
---

## Features

- User Registration
- User Login
- Browse games by genre
- Search games by designer
- View cart
- Checkout
- Logout

---

## Project Structure

```
Boardgame/
├── main.py # Main console program
├── database/ # Database initialization and db connection
├── src/ # All the project code (business logic)
├── .gitignore # git related configs
├── config.json # Configuration file
├── .env.example # Example file for environment variables
└── README.md # Project documentation
└── requirements.txt # Dependency list
```

---

## Installation

1. Clone the repository
    - git clone https://github.com/TharangaMahavila/BoardGame<br>
    - cd BoardGame
2. Install dependencies
    - You should have python running in your environment<br>
    - if not see the official installing page of python (https://www.python.org/downloads/)
    - pip install -r requirements.txt
3. Create .env file
    - Copy paste the .env.example file and rename it as .env file
    - Change your own values for the parameters
3. Usage
    - python3 main.py
